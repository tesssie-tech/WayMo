# WayMo

A high-performance, intelligent food discovery platform that learns what you love. This app goes beyond simple scrolling by using a custom recommendation algorithm to match users with their perfect meal.

## 🚀 Features

- **AI-Driven Menu Recommendations**: Personalized "For You" section that evolves based on your click history and dietary preferences.
- **Real-time Order Tracking**: Dynamic progress bars and simulated delivery status updates.
- **Smart Filter System**: Instant sorting by delivery time, rating, or "Health Score."
- **Responsive Design**: A mobile-first approach ensuring a seamless experience from desktop to smartphone.
- **Interactive Shopping Cart**: Smooth state management for adding, removing, and updating orders.

## 🛠️ Tech Stack

- **Frontend**:
  - HTML for page structure
  - CSS (with CSS variables for the palette) for styling and layout
  - Vanilla JavaScript for interactivity (DOM manipulation, event listeners, localStorage, history API)

It's a lightweight, framework-free frontend that works directly in the browser without any build step or dependencies.

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/tesssie-tech/WayMo.git
   ```
2. Navigate to the project directory:
   ```bash
   cd WayMo
   ```
3. Open `index.html` in your web browser.

## Usage

- Open the app in your browser.
- Browse menus and use the "For You" section for personalized recommendations.
- Add items to your cart and track orders in real-time.
- Use filters to sort by delivery time, rating, or health score.
